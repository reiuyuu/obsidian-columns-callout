# Columns Callout

Create multi-column layouts with `[!cols]` callout.

Columns are separated with `+++`.

```md
> [!cols]
> First column
>
> +++
>
> Second column
```

Options (callout title):

- `r` — column ratios (default: equal)
- `g` — column gap    (default: 1rem)

```md
> [!cols] r=2:1, g=2rem
```
